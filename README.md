# COVID-19 Management System

## Overview
The COVID-19 Management System is a C++ based application designed to manage information related to COVID-19, including patient data, doctor data, and details about various centers. The system is designed to help streamline the management and tracking of COVID-19 related information.

## Files and Directories
- **Covid-Management-System.cpp**: The main source code file for the application.
- **Doctor_Data.dat**: Data file containing information about doctors.
- **Patient_Data.dat**: Data file containing information about patients.
- **center1.txt, center2.txt, center3.txt**: Text files containing information about different centers.
- **rak12s.txt, sa12t.txt**: Additional text files used by the system.
- **preview.png**: A preview image, possibly showing a screenshot of the application.
- **README.md**: The existing README file (superseded by this one).

## Compilation and Execution

### Prerequisites
- A C++ compiler (e.g., g++, clang++)
- Standard C++ library

### Steps to Compile
1. Open a terminal (Command Prompt, PowerShell, or a terminal emulator on Linux/Mac).
   
2. Navigate to the directory containing the source code file (`Covid-Management-System.cpp`).

3. Compile the source code using your C++ compiler. For example, with g++:
   ```bash
   g++ -o Covid-Management-System Covid-Management-System.cpp
